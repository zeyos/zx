# Groupbox

A collapsible section built on native `<details>`, so the keyboard and find-in-page behaviour comes from the platform.

Full reference: https://zx.zeyos.com/docs/llms.md · Live demo: https://zx.zeyos.com/docs.html#components/groupbox · All components: https://zx.zeyos.com/docs/components/index.md

Collapsible titled section built on the native `<details>` element.

- **Options** — `title`, `open: true`.
- **Methods** — `open()`, `close()`, `toggle()`, `isOpen()`, `setTitle()`, `setContent()`.
- **Events** — `open`, `close`.
