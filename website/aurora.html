Zx.Aurora

Ambient light, not wallpaper.

Aurora adds a restrained multicolour light field behind an existing surface. Content, routing, overlays, and interaction remain application-owned.

Usage

Decorate; do not relocate.

Pass any existing surface. Aurora only adds its class, state attributes, and four colour properties. Destroying it restores the target exactly.

  • Use one colour for a module wash or up to four for a spectrum.
  • Keep Subtle for reading surfaces; use Balanced where glass needs more colour.
  • Forced-colours and reduced-transparency modes receive a flat surface.
import { Aurora } from '@zeyos/zx';

const aurora = new Aurora('#workspace', {
  preset: 'source',
  colors: ['#21cc75', '#2b7fff', '#9a67ff', '#ffb900'],
  intensity: 'balanced'
});

aurora.setPreset('horizon');
