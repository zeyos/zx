What arrived in 4.3

Scheduling, three record views over one contract, an ambient light layer, and a real overlay material — each with the keyboard map, accessible fallbacks, and zero dependencies the rest of the system already commits to.

  • Calendar

    Agenda, day, week, month, and year views with local-time collision layout, multi-day lanes, range selection, and equivalent pointer and keyboard move and resize.

  • Record views

    TableView, CardView, and KanbanView share one field, sort, selection, and versioned view-state contract — with swim lanes, WIP limits, and cancelable moves on the board.

  • Aurora

    A one- to four-colour ambient light field in six geometries. CSS-only, pointer transparent, and flat again under reduced transparency or forced colours.

  • Sheet & Dock

    Edge-anchored sheets with snap detents and swipe dismissal, drill-down stacks, and a dock of collapsible resizable panes that can adopt a sheet outright.

  • Liquid glass

    Compact overlays and reading panels draw on separate translucent materials, with deterministic opaque fallbacks wherever blur or transparency is unwelcome.

  • Application identity

    Circular chromatic lenses for applications, low-radius chips for entities and records — one shape language across Launcher, AppSidebar, and every module surface.

Design principles

Coherent, adaptive, and made for real work

Every Xenon decision should reduce relearning across modules while keeping high-volume work fast. The system grows from documented behavior, not isolated visual treatments.

Durable by default

Plain ES2022 modules with no runtime package, bundler, or framework to maintain.

Inclusive by default

Keyboard-complete controls, semantic markup, and explicit screen-reader behavior.

Adaptive, not fragmented

Semantic light, dark, cozy, compact, and responsive behavior across the same API.

Composed in layers

Foundations lead to components, patterns, and layouts instead of one-off screens.

Task and role focused

Dense enterprise flows prioritize the user’s next decision, not decorative chrome.

Incrementally adoptable

Current DOM and UI seams let existing application logic move one surface at a time.

Quick start

Use the Zx implementation directly

Import Xenon’s components in a modern application, or drop the Zx global bundle into an established ZeyOS screen. Both expose the same dependency-free API.

npm install @zeyos/zx or load dist/zx.global.js straight from jsDelivr — no install at all.

ES module

<link rel="stylesheet" href="/assets/zx.css">
<script type="module">
  import { Toggle } from '/assets/zx.esm.js';

  const toggle = new Toggle(null, {
    label: 'Notifications'
  });
  document.body.append(toggle.toElement());
</script>

Global script

<link rel="stylesheet" href="/assets/zx.css">
<script src="/assets/zx.global.js"></script>
<script>
  const toggle = new zx.Toggle(null, {
    label: 'Notifications'
  });
  document.body.append(toggle.toElement());
</script>
