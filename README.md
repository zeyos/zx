# Zx

Zx is a dependency-free, vanilla-JavaScript UI component library for the ZeyOS ERP. It is the
successor to the MooTools-based \`gx\` library and runs directly in modern browsers as ES modules.

## Status

| Work package | Status |
| --- | --- |
| WP0 — Scaffold, design tokens, demo harness | Complete |
| WP1 — Core kernel | Planned |
| WP2–WP10 — Components and custom elements | Planned |
| WP11 — Build and distribution | Planned |

The \`gx\` compatibility layer is upcoming.

## Development

Install the development tooling and run the no-build demo harness:

\`\`\`sh
npm install
npm run serve
\`\`\`

Then open <http://127.0.0.1:8321/demos/>.

Run the test suite and token lint with:

\`\`\`sh
npm test
\`\`\`
